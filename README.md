## 🚧 Featured Project

### [⏱️ tminus](https://github.com/Ashutoshbishtt/tminus) — Quick-Commerce Delivery Backend

A dispatch backend built to get every order out **in under 10 minutes**. The easy part is the ordering API — the hard part is **dispatch**: continuously matching a flood of incoming orders to riders moving across the city, correctly and fast, even when brokers restart or workers die mid-trip.

Built around invariants the system must **never** break:

- 🎯 One order never goes to two riders — even on duplicate message delivery or a mid-flight restart
- 📦 Stock is never oversold, and no order ever silently disappears
- 🔁 Nothing happens twice when it should happen once

Ships with a **load simulator** (thousands of fake riders, lunch/dinner rush spikes, deterministic seeds) and a **chaos test harness** that kills brokers, workers, and slows the DB on purpose — then verifies the invariants held.
