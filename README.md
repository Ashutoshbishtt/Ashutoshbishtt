# 🚧 Featured Project

## [⏱️ tminus](https://github.com/Ashutoshbishtt/tminus) — Quick-Commerce Delivery Backend

A distributed dispatch backend built to deliver every order in **under 10 minutes**.

The challenge isn't creating an order—it's continuously matching thousands of incoming orders with moving riders while handling retries, duplicate messages, worker crashes, and broker failures without violating business correctness.

### Core guarantees

- 🎯 One order is never assigned to multiple riders
- 📦 Inventory is never oversold
- 🔁 Operations remain idempotent during retries and failures
- ⚡ Orders continue flowing despite worker or broker failures

Includes a **load simulator**, **chaos testing framework**, and deterministic test scenarios for validating system correctness under production-like conditions.
